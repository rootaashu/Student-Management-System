# 🎓 Student Management System (C)

A simple Student Management System built using C that allows basic operations like storing and managing student records.

---

## 📌 Description

This project is a console-based application written in C to manage student data.

It demonstrates:

* File handling
* Structures in C
* Basic CRUD operations (Create, Read, Update, Delete)

---

## 🚀 Features

* Add new student records
* View all students
* Search student by ID
* Delete student record
* Update student details

---

## 🛠️ Tech Stack

* Language: C
* Concepts: File Handling, Structures, Pointers

---

## ▶️ How to Run

### 1. Compile

```bash
gcc src/student_manager.c -o main
```

### 2. Run

```bash
./main
```
